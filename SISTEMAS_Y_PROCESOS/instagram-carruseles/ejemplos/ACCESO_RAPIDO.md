## 📋 PASOS PARA EXPORTAR A PNG

### Opción 1: Manual (PrintScreen)
```
1. Abre HTML en navegador (Ctrl+O y selecciona archivo)
2. Para cada slide:
   - Desliza el carrusel
   - Posiciona slide en centro
   - Presiona PrintScreen
   - Abre Paint, pega (Ctrl+V)
   - Recorta a 1080 x 1350 px
   - Guarda como PNG
```

### Opción 2: Con herramienta (Recomendado)
```
1. Descarga Snagit o ShareX (gratis)
2. Abre HTML en navegador
3. Usa la herramienta para capturar área
4. Selecciona 1080 x 1350 px
5. Exporta PNG
```

### Opción 3: Script Playwright (Automático)
```
Si quieres que cree un script que exporte todos los PNG automáticamente,
avísame y lo hago.
```
