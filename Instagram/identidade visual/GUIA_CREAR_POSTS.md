## 🎨 Elegir Tipo de Post

### Opción A: Carrusel Completo (8 slides)
**Estructura:** Hook → Problema → Solución → Pasos → Resultados → CTA

**Cuándo usar:**
- Tutoriales completos
- Procesos paso a paso
- Argumentos de venta
- Transformaciones

**Ejemplo pilar:** Tutoriales, Agentes

**Tiempo de creación:** 45 min

---

### Opción B: Comparativa (5 slides)
**Estructura:** Hook → Antes/Después → Cómo → Resultado → CTA

**Cuándo usar:**
- Casos de éxito
- Transformaciones empresariales
- Ventajas de una solución
- Antes/Después reales

**Ejemplo pilar:** Clínicas, Casos de Éxito

**Tiempo de creación:** 35 min

---

### Opción C: Mini Datos (1 slide)
**Estructura:** Número grande → Descripción → Contexto

**Cuándo usar:**
- Estadísticas rápidas
- Teasers de posts
- Números impactantes
- Hechos sorprendentes

**Ejemplo pilar:** Cualquiera (para teasers)

**Tiempo de creación:** 15 min

## 📝 Paso a Paso Creación

### 1️⃣ PREPARACIÓN (5 minutos)

#### Abre Canva o Figma
```
Canva:
- Nuevo diseño
- Busca dimensión: 1080 x 1350 px
- O usa template "Instagram Post"

Figma:
- Nuevo archivo
- Artboard 1080 x 1350 px
- Nombra: [PILAR]_[NUMERO]_[TITULO]
```

#### Define tu Contenido
Antes de tocar el diseño, escribe en un papel o nota:

```
PILAR: [Agentes/Clínicas/Tutoriales/Casos]
TEMA: ¿De qué va el post?
GANCHO: ¿Cuál es el número/beneficio principal?
PUNTOS: ¿Cuáles son 3-5 puntos clave?
CTA: ¿Qué acción quieres que hagan?

Ejemplo:
PILAR: AGENTES
TEMA: Generar leads automáticamente
GANCHO: +500 leads/mes
PUNTOS:
  1. Usa Zapier para conectar herramientas
  2. ChatGPT responde automáticamente
  3. Tus prospectos se califican solos
  4. Tú solo hablas con leads calientes
CTA: Escribe "ZAPIER" en DM
```

---

### 2️⃣ SLIDE 1 - HOOK (5 minutos)

**Objetivo:** Captar atención en 1 segundo

#### Estructura
```
┌─────────────────────────────────────┐
│     [Fondo: #0B1220]                │
│                                     │
│     [NÚMERO GIGANTE]                │
│     +500 leads/mes                  │
│     (Color: #FFB020)                │
│     (Tamaño: 56-72px)               │
│                                     │
│     [Subtítulo]                     │
│     Genéralo automáticamente         │
│     (Poppins SemiBold, 24px)        │
│     (Color: #F5F7FA)                │
│                                     │
│     [Ícono pilar: esquina arriba]  │
│     ⚡ (Azul Eléctrico)            │
│                                     │
└─────────────────────────────────────┘
```

#### Pasos en Canva
1. Establece fondo: Color sólido #0B1220
2. Añade figura: Rectángulo (sin relleno, solo borde)
   - Borde: #3D5AFE, 3px
   - Tamaño: 300x150px
3. Dentro del rectángulo, agrega número
   - Texto: "500"
   - Fuente: Poppins Bold, 56px
   - Color: #FFB020
4. Bajo el número, agrega unidad
   - Texto: "leads/mes"
   - Fuente: Inter Regular, 18px
   - Color: #F5F7FA
5. Arriba del número, agrega subtítulo
   - Texto: "Genera"
   - Fuente: Inter Regular, 16px
   - Color: #3D5AFE
6. Bajo la caja, agrega descripción
   - Texto: "Automáticamente, sin tocar un email"
   - Fuente: Poppins Regular, 20px
   - Color: #F5F7FA
7. Ícono esquina superior derecha
   - Emoji: ⚡
   - Tamaño: 40px
8. Ícono CTRL esquina inferior derecha
   - Texto: "CTRL"
   - Tamaño: 24px
   - Opacidad: 50%
   - Color: #3D5AFE

## 🎯 Los 4 Pilares de Contenido

### PILAR 1: AGENTES DE VENTA ⚡

**Tema:** Automatización, lead generation, sales automation

**Estructura típica:**
- Hook: Número de leads/ventas
- Problema: Proceso manual, lento, caro
- Solución: Herramientas IA (Zapier, ChatGPT, etc)
- Pasos: 3-4 pasos técnicos
- Resultado: +X leads, -Y horas, $Z ingresos
- CTA: "ESCRIBE 'AGENTES' EN DM"

**Ejemplos de posts:**
```
1. +500 leads/mes automáticamente (Zapier + ChatGPT)
2. Chatbot WhatsApp para calificar clientes
3. Email automation con Make.com
4. Pipeline automático de ventas B2B
5. Prospecting automático con Python
```

**Métricas a destacar:**
- Número de leads
- Dinero ahorrado (horas × precio)
- Tasa de conversión
- ROI de la automatización

---

### PILAR 2: CLÍNICAS/SERVICIOS ✨

**Tema:** Retención, transformación empresarial, casos de éxito

**Estructura típica:**
- Hook: Porcentaje de mejora (retención, ingresos, etc)
- Antes: Estado anterior (caos, manual, bajo income)
- Después: Estado actual (orden, automático, alto income)
- Cómo: 3-4 implementaciones específicas
- Resultado: Métricas reales de la transformación
- CTA: "ESCRIBE 'CLÍNICA' EN DM"

**Ejemplos de posts:**
```
1. +60% retención de pacientes en 90 días
2. Doble ingresos con sistema CRM
3. -10h administrativas por semana
4. Testimonio: de caos a orden en 3 meses
5. Transformación: clínica que recibía 50 pacientes/mes → 120/mes
```

**Métricas a destacar:**
- Porcentaje de retención
- Nuevo income/revenue
- Horas ahorradas
- Cantidad de clientes/pacientes
- NPS o satisfacción

---

### PILAR 3: TUTORIALES TÉCNICOS 🎓

**Tema:** Educación, cómo usar herramientas, paso a paso

**Estructura típica:**
- Hook: Beneficio de aprender esto ("en 10 minutos")
- Contexto: Por qué es importante
- Pasos: 4-6 pasos muy claros
- Herramientas: Qué necesitas (gratis/pago)
- Resultado: Qué logras al final
- CTA: Descarga plantilla o ve más en bio

**Ejemplos de posts:**
```
1. Crea un Chatbot en 10 minutos con Claude + Zapier
2. Genera prompts de IA que conviertan (template incluida)
3. Automatiza tu email con Make.com (paso a paso)
4. Landing page con Bolt + Google Veo3 (demostración)
5. CRM gratis: Airtable como base de datos de clientes
```

**Métricas a destacar:**
- Tiempo requerido
- Herramientas necesarias (gratis vs pago)
- Nivel de dificultad
- Costo de implementación

---

### PILAR 4: CASOS DE ÉXITO PROPIOS 🚀

**Tema:** Resultados, transformación con Método CTRL

**Estructura típica:**
- Hook: Número impactante ($, %, clientes)
- Cliente/Contexto: Quién era, qué hacía
- Problema: Qué le limitaba
- Solución: Cómo implementó CTRL
- Resultado: Métricas después de 90 días
- CTA: "ESCRIBE 'CTRL' EN DM"

**Ejemplos de posts:**
```
1. $400k generados en 90 días (agencia digital)
2. De 5 clientes a 25 clientes en 6 meses
3. Automaticé mi negocio y trabajé -10h/semana
4. Duplicamos ingresos sin contratar gente
5. De freelancer a emprendedor: +$300k/año
```

**Métricas a destacar:**
- Dinero generado
- Número de clientes conseguidos
- Horas ahorradas
- Crecimiento en porcentaje
- Tiempo para implementar

- [ ] Body: Inter Regular (14-18px)
- [ ] Números: Poppins Bold, 24px+, #FFB020

- [ ] Ícono del pilar presente (⚡, ✨, 🎓, 🚀)

## 📤 Publicación

### Antes de Publicar

1. **Exporta desde Canva/Figma:**
   ```
   Formato: JPG
   Calidad: 85-90%
   Nombre: AGENTES_001_GENERAR_LEADS.jpg
   Carpeta: Instagram/carruseles/[PILAR]/
   ```

2. **Abre Meta Business Suite o Instagram directamente:**
   ```
   instagram.com (en web)
   O app Instagram en celular
   ```

3. **Sube el carrusel:**
   - Click en crear post (+)
   - Elige "Carrusel"
   - Arrastra imágenes en orden (slide 1 → slide 8)
   - Verifica orden es correcto

4. **Escribe el Caption:**
   ```
   Línea 1: Hook impactante
   
   Línea 2: Contexto/beneficio
   
   Línea 3-5: Detalles, call-to-action
   
   ---
   
   #IA #Automatización #NegocioDigital #CTRL
   #DesarrolloSinCodigo #Emprendimiento
   ```

5. **Configura:**
   - Ubicación: Omitir (o agregar tu ciudad)
   - Etiquetas de personas: No (salvo testimonios)
   - Accesibilidad: Escribe alt text (breve)

6. **Programa o publica:**
   ```
   Mejor momento: Martes-Viernes, 8am-6pm
   Ideal: Publicar 1-2 veces por semana
   ```

## 📊 Métricas a Seguir

Después de publicar, revisa:

| Métrica | Target Inicial | Meta Escalada |
|---------|----------------|---------------|
| Impresiones | 200+ | 1000+ |
| Alcance | 150+ | 500+ |
| Guardados | 10+ | 50+ |
| Compartidos | 5+ | 20+ |
| Clics en DM | 3+ | 15+ |
| Clics "Link en bio" | 2+ | 10+ |
| Retención | >60% | >70% |

**Si alguna métrica está baja:**
- Cambia el gancho del post
- Prueba con hora diferente
- Agrega más números/datos
- Asegúrate CTA sea clara
