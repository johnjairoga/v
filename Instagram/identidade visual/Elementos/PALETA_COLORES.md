## Notas de Implementación

- **Asegúrate de usar HEX exacto** en Canva/Figma para consistencia
- **RGB es alternativa** si la herramienta no soporta HEX
- **No mezcles colores** fuera de estas definiciones
- **Revisar contraste** cuando uses fondos alternos
- **Las variaciones de opacidad** son aceptables (80%, 60%, etc) para sutileza
