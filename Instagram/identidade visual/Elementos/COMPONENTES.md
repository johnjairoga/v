## Cómo Usar Estos Componentes

### En Canva:
1. Abre un diseño nuevo (1080x1350)
2. Busca "Shapes" → Rectángulo
3. Personaliza color, borde, tamaño
4. Agrega texto usando las fuentes recomendadas
5. Guarda como "componente" para reutilizar

### En Figma:
1. Crea un símbolo (Component)
2. Establece propiedades variables
3. Crea variaciones por pilar/color
4. Usa en múltiples slides

### Regla General:
- **Mantén consistencia:** Usa los mismos componentes en todos los slides
- **No mezcles:** No inventes nuevos estilos
- **Reutiliza:** Si necesitas algo nuevo, agrega a esta lista (versión 2.0)
