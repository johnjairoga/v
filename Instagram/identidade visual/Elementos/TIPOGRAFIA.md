# 🔤 Tipografía - @johnjairo.ai

## Fuentes Principales

### H1 - Títulos Principales
**Fuente:** Poppins Bold / Montserrat Bold (700)
- **Tamaño:** 36-48px (en slides)
- **Tracking:** +2px (espaciado entre letras)
- **Line-height:** 1.2
- **Color:** #F5F7FA o #FFB020
- **Uso:** Hook principal, números destacados, títulos de slide

**Ejemplo:**
```
"Gana +$1000"
"Automatiza tu negocio"
"Método CTRL"
```

---

### H2 - Subtítulos
**Fuente:** Poppins SemiBold / Inter SemiBold (600)
- **Tamaño:** 24-28px
- **Tracking:** +0.5px
- **Line-height:** 1.3
- **Color:** #3D5AFE o #F5F7FA
- **Uso:** Subtítulos, encabezados de sección

**Ejemplo:**
```
"creando landing pages con IA"
"Sin saber programar"
```

---

### H3 - Puntos Principales
**Fuente:** Inter SemiBold (600)
- **Tamaño:** 18-20px
- **Line-height:** 1.4
- **Color:** #F5F7FA
- **Uso:** Puntos clave, descriptores

**Ejemplo:**
```
• Automatiza respuestas
• Genera 500+ leads
• Sin tocar un email
```

---

### Body - Texto Principal
**Fuente:** Inter Regular / Poppins Regular (400)
- **Tamaño:** 14-18px
- **Line-height:** 1.5-1.6
- **Color:** #F5F7FA
- **Tracking:** 0px
- **Uso:** Descripción, explicación, contenido

**Ejemplo:**
```
"Implementa el Método CTRL en 90 días.
Más clientes, menos caos."
```

---

### Números/Datos - Destacado
**Fuente:** Poppins Bold / Montserrat Bold (700)
- **Tamaño:** Mínimo 24px (preferible 36px+)
- **Color:** #FFB020 (Ámbar siempre)
- **Tracking:** +1px
- **Uso:** Números clave, métricas, resultados

**Ejemplo:**
```
$1000
+60%
90 días
500+ leads
```

---

## Jerarquía Visual por Slide

### Estructura Recomendada (8 slides)

**SLIDE 1 (Hook):**
```
48px Bold (H1) → Gancho principal
36px SemiBold (H2) → Número o beneficio
18px Regular (Body) → Subtítulo
```

**SLIDE 2-7 (Contenido):**
```
28px SemiBold (H2) → Título de slide
18px Regular (Body) → Descripción
16px Regular (Body) → Puntos (con bullets)
24px Bold (Números) → Datos/métricas
```

**SLIDE 8 (CTA):**
```
36px Bold (H1) → Llamada a acción
20px Regular (Body) → Instrucción
18px SemiBold (H2) → Texto del botón
```

## Reglas de Espaciado

### Margen (Padding)
- **Exterior (de bordes):** Mínimo 20px
- **Entre secciones:** 30-40px
- **Entre líneas de texto:** 16-24px

### Alineación
- **Títulos:** Centro o izquierda (consistente)
- **Body:** Centro o izquierda (no justificado)
- **Números:** Siempre centrados y destacados

---

## Estilos Especiales

### Énfasis en Palabras
Para destacar palabras dentro del texto, usa:
```
Color: #3D5AFE (Azul Eléctrico)
Peso: SemiBold (600)
```

**Ejemplo:**
"Implementa el **Método CTRL** en 90 días"

### Superscripts
Para símbolos de dinero, porcentaje, etc.:
```
Tamaño: 80% del texto base
Altura: +2px
Color: #FFB020 (Ámbar)
```

**Ejemplo:**
"$1000+ por proyecto"

## Checklist de Tipografía

Antes de publicar cada slide:

- [ ] Título: Poppins Bold, 36-48px
- [ ] Subtítulo: Inter SemiBold, 24-28px
- [ ] Body: Inter Regular, 14-18px
- [ ] Números: Poppins Bold, 24px+, #FFB020
- [ ] Contraste: Legible sobre fondo
- [ ] Espaciado: Respetado margen de 20px
- [ ] Fuente: Consistente en todo el slide
- [ ] Alineación: Centrada o consistente
- [ ] Line-height: Respetado (1.5 mínimo body)
