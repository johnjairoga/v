# 🎯 Iconografía & Elementos Visuales - @johnjairo.ai

## Ícono Principal: Método CTRL

### Versión Completa
```
Letras "CTRL" en Azul Eléctrico (#3D5AFE)
Fondo: Azul Noche (#0B1220)
Tamaño: Flexible (20px-80px)
Estilo: Bold, sans-serif (Poppins)
```

**Uso:**
- Watermark sutil en esquina inferior derecha
- Ícono en transiciones entre slides
- Logo en bio de Instagram
- Elemento decorativo en esquinas

---

### Versión Corta
```
Solo "Ⅽ" o símbolo de control
Color: #3D5AFE (Azul Eléctrico)
Tamaño: 16px-40px
```

**Uso:**
- Bullet points
- Separadores
- Pequeños decorativos

## Elementos Decorativos

### Líneas & Divisores
```
Color: #3D5AFE (Azul Eléctrico)
Grosor: 2-4px
Largo: Flexible (desde 20% a 100% del ancho)
Opacidad: 100% o 70% (para sutil)
Estilo: Sólida (no punteada)
```

**Uso:**
- Separadores entre secciones
- Subraya de títulos
- Línea decorativa horizontal/vertical

**Ejemplo:**
```
TÍTULO PRINCIPAL
────────────────
Subtítulo o descripción
```

---

### Puntos & Círculos
```
Color: #3D5AFE (Azul Eléctrico)
Tamaño: 4px-12px
Uso: Decorativos en esquinas, separadores
```

**Uso:**
- Esquina superior/inferior derecha
- Entre puntos de lista
- Conexiones visuales

---

### Marcos & Cajas
```
Borde: #3D5AFE (Azul Eléctrico)
Grosor: 2-3px
Border-radius: 12px (redondeado)
Fondo: #0B1220 (transparente o semi-opaco)
```

**Uso:**
- Destacar números clave
- Botones CTA
- Información importante

**Ejemplo:**
```
┌──────────────────────┐
│  ESCRIBE EN DM       │  (con borde azul)
└──────────────────────┘
```

---

### Flechas
```
Color: #3D5AFE (Azul Eléctrico) o #FFB020 (Ámbar)
Tamaño: 16px-32px
Dirección: Hacia números, CTAs, o resultados
```

**Uso:**
- Apuntar a números destacados
- Indicar progresión/pasos
- Guiar atención visual

**Ejemplo:**
```
→ Resultado: +$1000/mes
↓ Paso 1: Crea cuenta
↗ Aprende haciendo clic
```

## Guía de Consistencia

### Tamaños de Ícono
```
Pequeño (16px): Bullets, decorativos
Mediano (24px-32px): Badges, encabezados
Grande (48px+): Foco principal, impacto
```

### Colores de Ícono
```
Primario: #3D5AFE (Azul Eléctrico) - 70% del tiempo
Secundario: #FFB020 (Ámbar) - para urgencia
Éxito: #10B981 (Verde) - validaciones
Texto: #F5F7FA (Blanco Frío) - legibilidad
```

### Posicionamiento
```
Esquina superior derecha: Watermark CTRL
Esquina inferior derecha: Logo/marca
Centro: Ícono principal del contenido
Laterales: Decorativos, líneas, puntos
```

## Checklist de Iconografía

Antes de publicar:

- [ ] Ícono del pilar presente (⚡, ✨, 🎓 o 🚀)
- [ ] Colores de ícono consistentes
- [ ] Líneas decorativas en #3D5AFE
- [ ] Números con flecha o acento
- [ ] Badges bien formateados
- [ ] Emojis no excesivos (máximo 3-4 por slide)
- [ ] Tamaño de ícono legible (mínimo 20px)
- [ ] Watermark CTRL sutil en esquina
