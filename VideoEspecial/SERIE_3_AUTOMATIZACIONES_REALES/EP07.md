## HOOK

---

## ESTRUCTURA

### Capa 2 — El caso real

**El error:**
- Qué decía el prompt que estaba mal (muéstralo)
- Qué respondía el agente como consecuencia
- Por qué el cliente (la clínica) no lo notó al principio
- Cómo lo detectaron: ¿queja de paciente, revisión de métricas, auditoría interna?

**El impacto real:**
- Cuántos leads se perdieron (estimado)
- Cuánto tiempo estuvo el error activo
- Cómo afectó la confianza del cliente en el sistema

**La corrección:**
- El prompt corregido (antes vs después)
- Qué proceso de revisión implementaron para detectar esto antes
- Cómo comunicaron el error al cliente

**Material de respaldo:**
- [ ] El prompt original con el error (anonimizado)
- [ ] El prompt corregido
- [ ] Conversaciones del agente mostrando el error (anonimizadas)
- [ ] Métricas antes y después de la corrección

### Capa 3 — Aprendizaje

**Lección:** Cómo auditar un agente de IA en producción para detectar errores silenciosos.

**Puntos:**
- Los tipos de errores de prompt que más daño hacen sin que nadie lo note
- El proceso de revisión mínimo que debes tener si tienes clientes con agentes activos
- Cómo comunicar un error a un cliente sin perder su confianza
